Paramètres

La clé API se crée dans Omeka S : Utilisateurs → ton compte → Modifier → onglet « Clés API ». Sans clé, la page fonctionne en lecture seule. La clé reste dans ce navigateur : elle n'est jamais envoyée ailleurs qu'à ton Omeka S.

Se connecter

Ta connexion sert à savoir qui fait l'exercice : chaque passation est rattachée à ton compte (item artinq:Participant).

Connexion locale avec ton compte Omeka S : ton email et ta clé API (dans les Paramètres).

Connexion avec ton compte GitHub, grâce à un jeton d'accès personnel.

  1. Crée un jeton sur github.com/settings/personal-access-tokens/new (aucune permission à cocher : il sert juste à lire ton profil public).
  2. Colle-le ici. La page lit ton profil sur l'API GitHub puis oublie le jeton.

Connexion avec ton compte Google (Google Identity Services).

Connexion avec le CAS de l'université : tu es redirigé vers la page de connexion de l'université, puis renvoyé ici.

Serveur : (modifiable dans les Paramètres). Le serveur CAS doit accepter cette page comme service et autoriser la vérification du ticket depuis le navigateur.
